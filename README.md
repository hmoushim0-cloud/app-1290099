## Project Overview (نظرة عامة على المشروع)

تم تصميم النظام المعماري للهواتف الذكية بتقنية Kotlin Multiplatform لتقديم تجربة عميل فائقة السرعة والاستجابة عند الوصول من حملات إعلانات جوجل. يتضمن التطبيق مسارا تشغيليا ثلاثي المراحل يبدأ من استعراض خدمات التبريد وحساب التكلفة التقديرية، مرورا بتخصيص مواصفات المكيفات واختيار الموعد المناسب، وصولا إلى بوابة الدفع وإصدار الفاتورة الضريبية وتتبع موقع الفني مباشرة، مما يضمن أقصى عائد على الإنفاق الإعلاني.

## Core Features (المميزات الرئيسية)

- **حجز فوري لخدمات الصيانة والتركيب مع تحديد دقيق للموقع ونوع المنظومة**
- **أتمتة الفحص الدوري وجدولة زيارات الفنيين لتقليص زمن الانتظار**
- **إصدار فواتير ضريبية إلكترونية متوافقة ودفع رقمي آمن عبر مدى وفيزا**
- **تتبع مسار وصول الفنيين لحظيا عبر الخريطة مع توثيق تقارير الكشف الفني**

## Clean Architecture Layers

```
sa.factory.app1290099
├── data/
│   └── HvacMaintenanceContractRepository.kt          # Flow-based reactive data source
├── model/
│   └── HvacMaintenanceContractModels.kt              # Immutable business data structures
├── ui/
│   ├── MainActivity.kt                # Jetpack Compose Entry Activity
│   ├── HvacMaintenanceContractViewModel.kt           # StateFlow UI state holder
│   └── HvacMaintenanceContractScreens.kt             # Material 3 Compose vector screens
└── server/
    ├── package.json                   # Node.js + Socket.io dependencies
    ├── server.js                      # Realtime API Gateway & UUID Security
    └── deploy_vps.sh                  # 1-Click Production VPS Auto-Scaler
```

Run the automated VPS deployer on Ubuntu 22.04 / 24.04 (Hetzner / Contabo):
